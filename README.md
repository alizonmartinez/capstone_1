# Capstone 1: Maryland Sales Analysis

This project analyzes EmporiUm sales for Maryland in the Northeast region.

Analyzes includes in-store and online sales. Ranges from January 1,2022 to December 31,2025.

This project answers the questions about:
    - Total Maryland revenue
    - Monthly and yearly revenue
    - In-store revenue vs online revenue
    - Total transactions and average transaction amounts
    - Product category performance
    - Individual Maryland store performance
    - Recommendations for the next quarter

Files for this project:
    - sample_sales_all.sql
    - Martinez_sales_analysis.sql
    - Martinez_additional_questions.sql
    - Martinez_territory_chart.xlsx
